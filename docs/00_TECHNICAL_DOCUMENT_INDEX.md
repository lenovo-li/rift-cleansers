## 核心结论速查

### 技术栈（文档01）

- **引擎**：Godot 4.7.x 稳定版（当前最新 4.7.2，M0 起锁定小版本）
- **主语言**：GDScript（强制类型标注）
- **联机模型**：主机权威 Listen Server
- **开发期传输**：ENet（Godot高层多人API）
- **Steam传输**：GodotSteam MultiplayerPeer + Steam Relay
- **渲染方向**：平滑中模3D + 俯视固定镜头

### 开发顺序（文档07）

```
M0: 技术试验（2周）
  ↓
M1: 10分钟单人灰盒（4-6周）
  ↓
M2: 2人联机原型（3-4周）
  ↓
M3: 垂直切片美术（8-12周）
  ↓
M4: 1-4人完整联机（6-8周）
  ↓
M5: 内容扩充与Beta（4-6月）
```

### 最大技术风险（文档09）

1. **后期敌人数量CPU瓶颈** → 第一个月建立1000敌人压测
2. **四人特效GPU瓶颈** → 队友透明度、质量档、MultiMesh
3. **联机状态分叉** → 主机权威、固定种子、早期2人验证
