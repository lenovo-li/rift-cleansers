# 《裂界清扫者》10分钟垂直切片计划

> 版本：v1.0  
> 日期：2026-09-27  
> 工期：4-6周  
> 状态：待启动

---

## 执行摘要

**目标**：完成一个10分钟可玩的单人版本，验证核心体验

**范围**：严格限制内容数量，聚焦核心循环质量

**退出条件**：
1. 第1分钟升级3-5次
2. 第5分钟形成流派
3. 第10分钟仍期待继续升级
4. 死亡原因可识别
5. 一个技能有明显四段进化
6. 中端PC稳定60 FPS
7. 核心逻辑具备联网改造条件

---

## 1. 内容范围（严格限制）

### 1.1 角色

**数量**：1个

**选择**：铁卫（近战、聚怪、反击）

**理由**：
- 近战玩法易于实现和调试
- 聚怪机制测试敌人AI
- 反击验证伤害系统

**配置**：
```yaml
character_id: ironguard
base_health: 1000
base_move_speed: 250
base_damage: 50
resource_type: rage
starting_skills: [shield_bash, taunt]
```

### 1.2 主技能

**数量**：6个

| 技能ID | 名称 | 类型 | 完整进化 |
|---|---|---|---|
| shield_bash | 盾击 | 近战冲撞 | ✓ 1/3/5/8级 |
| taunt | 嘲讽 | 聚怪 | - |
| whirlwind | 旋风斩 | 范围持续 | - |
| charge | 冲锋 | 位移 | - |
| ground_slam | 震地 | 范围控制 | - |
| reflect_aura | 反射光环 | 被动反伤 | - |

**盾击四段进化**（示例）：
- **1级**：前方锥形冲撞，击退1个敌人
- **3级**：击中3个敌人，被击退敌人撞到其他敌人造成连锁伤害
- **5级**：冲撞距离+50%，末端产生冲击波
- **8级**：冲撞路径留下火焰地带，持续3秒

### 1.3 被动模块

**数量**：4个

| 模块ID | 名称 | 效果 |
|---|---|---|
| block_recovery | 格挡回复 | 格挡时恢复10护盾 |

| revenge | 复仇 | 受击后5秒内攻速+20% |

**数量**：6件

**普通敌人**：4种

```yaml
  - teleporter: 传送（生命<30%时传送）
  - vampire: 吸血（攻击吸血20%）

```

### 1.6 Boss

**数量**：1个简单Boss

**Boss ID**：corrupted_knight（腐化骑士）

**阶段**：
- **阶段1（100%-60%）**：近战攻击+定期召唤小怪
- **阶段2（60%-30%）**：增加冲锋技能
- **阶段3（30%-0%）**：狂暴，攻速+50%，持续召唤

**机制**：
- 召唤4波小怪（每波5只）
- 冲锋预警1秒，红色箭头指示
- 狂暴阶段每5秒召唤1只精英

| 减速+击退 | 碎裂 | 被减速的敌人受到击退时额外伤害 |

### 1.8 地图

**数量**：1个简单地图

**地图**：训练场（Training Ground）

**规格**：
- 尺寸：1600×1200像素

## 2. 核心循环设计

### 2.1 时间线

| 时间 | 玩家等级 | 敌人密度 | 关键事件 |
|---:|---:|---|---|
| 0:00-1:00 | 1-5 | 10-20 | 快速升级，习惯操作 |
| 1:00-3:00 | 5-10 | 30-50 | 获得第一件装备 |
| 3:00-5:00 | 10-15 | 60-100 | 技能进化到3级 |
| 5:00-7:00 | 15-20 | 120-200 | 第一个精英，技能5级 |
| 7:00-9:00 | 20-25 | 250-400 | 多个精英，技能8级 |
| 9:00-10:00 | 25-30 | Boss战 | 简单Boss，3阶段 |

### 2.2 升级节奏

```gdscript
# 经验需求曲线
func get_exp_required(level: int) -> float:
    return 20 + level * 8  # 1级:28, 5级:60, 10级:100

# 首分钟经验倍率
func get_exp_multiplier(game_time: float) -> float:
    if game_time < 60:
        return 2.0  # 前1分钟双倍经验
    elif game_time < 180:
        return 1.5  # 1-3分钟1.5倍
    else:
        return 1.0
```

### 2.3 掉落节奏

| 时间 | 装备掉落 | 装备品质 |
|---:|---:|---|
| 1:00 | 第1件 | 普通 |
| 3:00 | 第2件 | 普通 |
| 5:00 | 第3件 | 稀有 |
| 7:00 | 第4件 | 稀有 |
| 9:00 | 第5件 | 传奇（Boss前） |

## 6. 退出条件详解

### 6.1 第1分钟升级3-5次

**测试**：
```gdscript
func test_early_level_progression():
    var session = start_test_game()
    simulate_gameplay(60.0)  # 60秒
    assert(player.level >= 4 and player.level <= 6)
```

**如果失败**：
- 增加初始经验倍率
- 降低前5级经验需求
- 增加初始敌人密度

### 6.2 第5分钟形成流派

**测试**：玩家访谈

**问题**：
- "5分钟时你的构筑方向是什么？"
- "你是聚怪流、反伤流还是冲锋流？"

**如果失败**：
- 技能协同不明显
- 升级选项过于随机
- 装备效果不够强

### 6.3 第10分钟仍期待继续升级

**测试**：玩家访谈

**问题**：
- "10分钟时你还想继续玩吗？"
- "下一次升级你期待什么？"

**如果失败**：
- 技能进化不够明显
- 数值成长过于线性
- 缺少质变时刻

### 6.4 死亡原因可识别

**测试**：玩家访谈

**问题**：
- "你是怎么死的？"
- "你看到攻击预警了吗？"

**如果失败**：
- 敌人攻击无前摇
- 危险区域不明显
- 伤害来源不可见

### 6.5 一个技能有明显四段变化

**测试**：录像对比

**验证**：
- 1级盾击 vs 3级盾击：视觉和机制都不同
- 5级盾击 vs 8级盾击：天差地别

**如果失败**：
- 只是数值增长
- 视觉无变化
- 机制无质变

### 6.6 中端PC稳定60 FPS

**测试**：性能测试

**配置**：
- CPU: Intel i5-8400 / Ryzen 5 3600
- GPU: GTX 1060 / RX 580
- RAM: 8 GB

**测试场景**：
- 500个敌人
- 全部技能同时释放
- 粒子全开

**如果失败**：
- 实施分层更新
- 启用MultiMesh
- 优化空间查询

### 6.7 核心逻辑具备联网改造条件

**检查清单**：
- [ ] 所有实体有entity_id
- [ ] 随机数使用RandomNumberGenerator
- [ ] 战斗规则不调用表现层
- [ ] 伤害由主机计算（架构上）
- [ ] 快照可序列化

**如果失败**：
- 重构分离规则和表现
- 引入稳定ID系统
- 重构随机数

## 7. 风险与应对

### 7.1 技术风险

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 500敌人性能不足 | 中 | 高 | Week 1完成压测，提前优化 |
| Boss战不有趣 | 高 | 中 | Week 3完成Boss，留1周调优 |
| 数值平衡困难 | 高 | 低 | 使用配置文件，快速迭代 |
| 架构不支持联网 | 低 | 高 | Week 1检查架构分层 |

### 7.2 内容风险

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 6个技能不够多样 | 中 | 中 | 聚焦质量，不扩充数量 |
| 10分钟太短无法展示 | 低 | 低 | 调整时间线，压缩前期 |
| 美术风格不统一 | 高 | 低 | 只使用1个素材包 |

### 7.3 进度风险

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| Week 4未完成核心循环 | 中 | 高 | 砍掉美术替换，灰盒发布 |
| Boss复杂度超预期 | 高 | 中 | 简化到单阶段 |
| 多系统交互Bug | 高 | 中 | Week 5专门修Bug |

## 9. 成功标准

只有同时满足以下条件，才进入M2联机原型：

- ✓ 10分钟完整循环可玩
- ✓ 退出条件全部通过
- ✓ 至少3名外部测试者愿意再玩一次
- ✓ 性能测试通过
- ✓ 架构检查清单通过
- ✓ 无P0/P1严重Bug

**如果失败**：
- 继续迭代垂直切片
- 重新评估核心玩法
- 不进入联机阶段
