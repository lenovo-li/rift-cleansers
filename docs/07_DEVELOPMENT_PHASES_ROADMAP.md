# 《裂界清扫者》开发阶段路线图

> 版本：v1.0  
> 日期：2026-09-27  
> 总工期：12-18个月（单人全职）  
> 状态：规划完成

---

## 执行摘要

**开发策略**：小步快跑，每个里程碑交付可玩构建

**核心原则**：
1. 先验证核心体验，再扩充内容
2. 早期验证联机，避免后期重构
3. 每周产生可玩构建
4. 性能从第一天监控
5. 不在未验证的基础上堆内容

---

## 里程碑总览

```
M0: 技术试验 (2周)
  ↓
M1: 10分钟单人灰盒 (4-6周)

```

## 性能监控

### 每周记录

```
Week X 性能报告
- 构建版本: v0.X.X
- 测试场景: 10分钟单人/4人15分钟
- 平均FPS: XX
- 1% Low: XX
- 活跃实体: XXX
- 内存峰值: XXX MB
- Draw Calls: XXX
- 带宽: XX KB/s
```

### 性能回归警告

- 平均FPS下降 >10% → 立即定位
- 1% Low <45 → P1优先级
- 内存增长 >50 MB → 检查泄漏
- 带宽增长 >50% → 检查同步

## 风险管理

### 高风险项

| 风险 | 检测时间 | 应对计划 |
|---|---|---|
| 1000敌人性能不足 | M0结束 | 切换引擎或降低目标 |
| 联机状态分叉 | M2结束 | 重构主机权威架构 |
| 四人特效混乱 | M4结束 | 队友透明度、质量档 |
| 内容产能不足 | M5中期 | 砍掉第2张地图 |

### 中风险项

| 风险 | 检测时间 | 应对计划 |
|---|---|---|
| 技能不够多样 | M1结束 | 聚焦质量，接受数量少 |
| Boss不有趣 | M1结束 | 简化机制，增加阶段数 |
| 美术风格不统一 | M3中期 | 只用1个素材包 |
| Steam集成失败 | M4中期 | 降级为纯ENet |
