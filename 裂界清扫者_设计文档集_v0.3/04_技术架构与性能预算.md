# 《裂界清扫者》技术架构与性能预算

## 1. 推荐技术栈

- 引擎：Godot 4.x稳定版
- 主语言：GDScript，强制类型标注
- 性能扩展：仅在Profiler确认热点后使用C++/GDExtension
- 版本控制：Git + Git LFS
- 3D：Blender
- 2D/UI：Krita + Inkscape
- 音频：Audacity
- GPU分析：RenderDoc

Godot采用MIT许可证，可以用于商业游戏，但发布时需要包含许可证和版权声明。[1]

## 2. 为什么选择Godot

- 免费开源，无引擎分成。
- 场景、UI、粒子、Shader和资源系统适合快速迭代。
- 可以使用GDScript、C#和C++扩展。
- 源码开放，出现底层问题时可以调查。
- 对单人开发者而言，编辑器和构建流程比自研引擎节省大量时间。

## 3. 模块划分

```text
project/
├─ addons/                   # 第三方插件
├─ core/                     # 无Godot场景依赖的规则逻辑
├─ gameplay/
│  ├─ actors/
│  ├─ abilities/
│  ├─ enemies/
│  ├─ items/
│  └─ encounters/
├─ net/                      # 传输、RPC、快照、重连
├─ presentation/             # 粒子、动画、音效、相机、UI
├─ content/                  # Resource配置
├─ scenes/
├─ tests/
└─ third_party_licenses/
```

## 4. 核心模块职责

- **GameSession**：人数、时间、种子、胜负、难度。
- **CombatSim**：属性、伤害、状态、技能和掉落规则。
- **SpawnDirector**：根据时间、人数和性能预算生成敌群。
- **NetSession**：连接、RPC、快照、重连和权限。
- **Presentation**：视觉、音频、UI和镜头反馈。
- **ContentDB**：读取角色、技能、装备、敌人和地图数据。

必须避免技能脚本直接调用Steam API，也不能让粒子逻辑决定最终伤害。

## 5. 数据驱动

角色、技能、装备和敌人使用Resource配置。配置至少包含：

- 稳定的整数或字符串ID
- 展示名称与描述
- 图标路径
- 基础数值
- 等级成长
- 标签
- 联携状态
- 表现资源
- 网络策略

配置与运行时状态分离，便于保存、重连、测试和批量平衡。

## 6. 大量敌人策略

### 6.1 不要这样做

不要让每只普通敌人都拥有：

- 完整CharacterBody
- 独立NavigationAgent
- 独立AnimationTree
- 多个Timer节点
- 每帧路径规划
- 每帧精确碰撞查询

### 6.2 推荐做法

- 对象池复用敌人、投射物、爆炸和数字。
- 近处敌人10至15Hz逻辑更新。
- 远处敌人2至5Hz简化更新。
- 使用空间网格对单位分桶。
- 范围技能查询网格，不遍历全部敌人。
- 同类敌人使用MultiMesh或实例化渲染。
- 远处敌人关闭复杂骨骼动画，以顶点摆动代替。
- 持续伤害按固定tick结算。
- 普通伤害数字0.2至0.5秒聚合显示。

## 7. 性能预算

| 指标 | MVP | 发布候选 |
|---|---:|---:|
| 目标帧率 | 中端PC单人60 FPS | 四人终局1080p 60 FPS，低配30 FPS档 |
| 活跃普通敌人 | 500 | 1000至2000，按质量档调整 |
| 玩家逻辑 | 30Hz | 30或60Hz |
| 普通敌人逻辑 | 10Hz | 10至15Hz |
| 远处敌人逻辑 | 2Hz | 2至5Hz |
| 网络平均流量 | 测量为准 | 每客户端尽量低于100 KB/s |
| 战斗临时分配 | 无明显尖峰 | 关键路径避免大数组临时分配 |

## 8. 随机数

- 局内使用服务器种子。
- 不同系统使用派生随机流，如掉落、刷怪、地图事件。
- 客户端不能决定掉落。
- 日志记录种子，方便复现Bug。

## 9. 存档

存档分为：

- 配置：按键、音量、画质、辅助功能
- 账户进度：角色、技能、地图、成就
- 局内恢复：仅用于断线重连或主机迁移

存档包含版本号，并提供逐版本迁移函数。不要直接序列化整个场景树。

## 10. 自动测试

优先自动化：

- 伤害公式
- 冷却与攻速边界
- 状态叠层和联携递归保护
- 升级权重和保底
- 人数缩放
- 配置ID唯一性
- 快照序列化与反序列化
- 固定种子的生成结果

## 11. 性能回归场景

建立固定种子的测试地图，支持直接跳转到：

- 第1分钟
- 第10分钟
- 第20分钟
- 第25分钟Boss阶段

每次发布构建记录：

- 平均帧时间
- 1% Low
- 活跃节点和对象数
- 内存峰值
- GC或分配尖峰
- Draw Calls
- 网络发送与接收速率
