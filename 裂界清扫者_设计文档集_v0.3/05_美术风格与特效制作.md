# 《裂界清扫者》美术风格与特效制作

## 1. 总体判断

对于只擅长写代码的单人开发者，最稳妥的方案是：

> **平滑中模3D（Blender 脚本程序化建模，顶点色）+ 俯视固定镜头 + 共享色板材质 + 程序化Shader和粒子特效。**

不建议首版选择：

- 高精度写实3D
- 大量逐帧2D动画
- 每个角色独立骨架和几十套动画
- 大量手绘场景插画
- 复杂PBR贴图流程

## 2. 风格规则

### 模型

- 风格：平滑中模（倒角 + 平滑着色 + 加权法线 + 顶点色假AO），像手办而非棱角分明的低多边形
- 普通敌人：约3000至5000三角面
- 玩家：约6000至10000三角面
- Boss：约5000至8000三角面，优先轮廓而非细节
- 地图零件：单件不超过5000三角面；小装饰不超过300三角面
- 性能底线：500 敌人同屏仍需保持流畅（MultiMesh + 共享材质）
- 武器与肩甲采用夸张比例
- 从俯视距离判断效果，不在建模软件近距离追求细节

### 材质

- 每个阵营使用一张共享调色板纹理，或直接使用顶点色。
- 普通单位尽量使用1个材质槽。
- 通过颜色、边缘光和溶解区分普通、精英和Boss。
- 不为每个敌人制作独立4K贴图。

### 色彩

- 玩家：高饱和、清晰轮廓
- 普通敌人：相对低饱和
- 精英：亮边、特殊色块或头顶标志
- Boss：高对比大轮廓
- 玩家火焰：橙红
- 玩家冰霜：青蓝
- 玩家雷电：蓝紫
- 玩家毒素：荧光绿
- 敌方危险攻击：固定红色或品红色

## 3. 角色与敌人复用

### 角色

同一基础身体通过以下部件形成差异：

- 头部
- 武器
- 肩甲
- 背部装置
- 色板
- 轮廓配件

### 敌人骨架族

每种骨架至少派生3种敌人。例如：

- 人形骨架：行尸、祭司、号角恶魔
- 四足骨架：冲锋兽、护甲兽、爆裂兽
- 漂浮骨架：水母、幽灵、符文眼
- 虫形骨架：幼虫、甲虫、孢子虫

通过尺寸、材质、头部和技能变化创造种类，不为每个敌人重做动画。

## 4. 最小动画集

普通敌人：

- 待机
- 移动
- 攻击
- 受击
- 死亡

玩家角色：

- 待机
- 移动
- 闪避
- 基础攻击
- 主动技能
- 受击
- 倒地
- 复活

很多自动技能不需要角色专属动画，可以通过武器节点、程序旋转和粒子表现。

## 5. 技能特效模板

每个技能由六层组成：

1. **核心形状**：圆、环、扇形、直线、螺旋或弧线
2. **主材质**：基础色、边缘高亮、噪声溶解
3. **粒子**：火星、碎屑、烟雾、电弧或冰片
4. **运动**：缩放、旋转、拖尾、回弹、冲击波
5. **打击反馈**：停顿、震动、音效、击退
6. **升级变化**：改变形态和节奏，而不是简单增加粒子数量

### 四档视觉成长

- 1级：小而清楚
- 3级：增加拖尾、二次命中或残留
- 5级：攻击形态质变
- 8级：天空、地面或环境级效果

## 6. 炫酷但低成本的技巧

- 用简单平面网格加滚动噪声制作能量波。
- 用圆环网格和溶解Shader制作冲击波。
- 用Ribbon/Trail制作刀光和电弧。
- 用短暂点光源加强爆炸，但限制同时数量。
- 用0.02至0.05秒命中停顿制造力量感。
- 用低频音效和瞬时缩放增强终极技能。
- 同一套粒子改变颜色、速度、尺寸即可派生多个元素版本。

## 7. UI方案

- 使用扁平色块和SVG图标。
- 固定8px或12px圆角体系。
- 只使用1至2种字体。
- 图标先用几何符号表达，再考虑精修。
- 玩家1至4使用蓝、黄、青、紫轮廓，并提供色盲预设。
- 升级卡片必须在移动过程中一眼看懂。

## 8. 不会Photoshop的工作流

- **Blender**：模型换色、拆件、缩放、骨骼检查和glTF导出。
- **Krita**：简单位图修改、裁切、图层和少量绘制。
- **Inkscape**：技能图标、UI图形和Logo。
- **Godot Shader**：溶解、描边、闪白、色板替换和特效。
- **Audacity**：裁剪、混音、响度和淡入淡出。

Blender是自由软件，可以用于建模和制作商业游戏资产；Krita也是自由开源绘画软件。[1][2]

## 9. 资产制作顺序

1. 使用胶囊、方块和圆形完成灰盒。
2. 用 Blender 脚本（tools/blender/）程序化生成统一风格的平滑中模，并保存 .blend 源文件。
3. 建立Blender导出模板。
4. 建立共享材质和色板。
5. 制作一个完整敌人骨架族。
6. 制作一个技能的四档视觉成长。
7. 固化特效模板后批量扩展。
8. 最后制作商店页和宣传图。
