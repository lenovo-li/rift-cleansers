# 《裂界清扫者》测试、发布与风险清单

## 1. 测试层级

### 规则测试

- 伤害公式
- 暴击和冷却边界
- 状态叠层
- 联携触发冷却
- 升级保底
- 角色与装备ID唯一性
- 存档版本迁移

### 战斗测试

- 第1、5、10、15、20、25分钟强度
- 单人是否出现无法完成机制
- 双人是否产生组合价值
- 四人可读性和性能
- 近战与远程构筑通关率

### 网络测试

- 0至150毫秒延迟
- 0%至3%丢包
- 主机低帧率
- 客户端掉线重连
- 主机退出
- 大量技能同时触发

### 兼容性测试

最低覆盖：

- Windows 10与Windows 11
- 集成显卡低画质档
- 主流NVIDIA与AMD独立显卡
- 16:9、16:10和超宽屏
- 键鼠、Xbox布局手柄和常见通用手柄

## 2. 关键指标

- 首分钟升级3至5次
- 第10分钟至少出现一次技能质变
- 单局死亡原因能够被玩家解释
- 四人终局仍能识别Boss危险区
- 双人联携触发频率足够，但不成为强制路径
- 1、2、3、4人各至少完成20局内部测试
- 20分钟后掉线重连不会丢失构筑

## 3. 试玩问卷

每局只问少量问题：

1. 哪一刻最爽？
2. 哪一次死亡最不明白？
3. 第10分钟是否还期待继续升级？
4. 是否能看清自己的角色？
5. 是否能看清Boss危险攻击？
6. 多人时有没有自然地与队友配合？
7. 最想立即再玩一次的原因是什么？

不要只问“好不好玩”，要记录具体时间点和构筑。

## 4. 日志与遥测

本地日志至少记录：

- 构建版本
- 地图与种子
- 玩家人数
- 角色和构筑
- 帧时间与内存峰值
- 网络延迟与丢包
- 死亡时间和来源
- Boss阶段
- 崩溃前关键事件

如果收集线上遥测，必须在隐私政策中说明，并只收集诊断所需数据。

## 5. 发布前检查

### 功能

- 新游戏、继续、退出均正常
- 单人不需要Steam连接
- 1至4人房间正常
- 掉线重连正常
- 存档升级正常
- 所有角色和技能可解锁

### 性能

- 固定终局压测通过
- 低画质档有效降低GPU和粒子压力
- 无持续内存增长
- 音效并发有上限

### 可读性

- 队友特效透明度可调
- 镜头震动、闪光和伤害数字可调
- 字体大小和色盲预设可用
- 敌方危险提示位于最高层

### 合规

- Godot许可证已包含
- 第三方插件许可证已包含
- 素材来源与署名完整
- 字体允许嵌入和商用
- 音乐、音效和Logo权利明确

## 6. 十大风险

| 风险 | 早期信号 | 应对 |
|---|---|---|
| 内容范围失控 | 同时制作很多角色和地图 | 锁定MVP，新增必须替换旧需求 |
| 后期掉帧 | 第10分钟已出现尖峰 | 从第一个月建立终局压测 |
| 四人画面混乱 | 玩家找不到自己 | 队友透明度、轮廓、危险层级 |
| 联机调试困难 | 规则脚本直接调用网络API | 规则、网络、表现分层 |
| 单人体验残缺 | 必须两人占点 | 所有机制提供单人流程 |
| 美术风格混杂 | 多来源素材直接拼接 | 只选一个基准包并统一材质 |
| 主机掉线损失 | 20分钟进度归零 | 先做奖励保护，再做迁移 |
| 技能只是数值成长 | 升级看不出变化 | 强制四档机制与视觉质变 |
| 免费素材侵权 | 找不到原始许可 | 资产登记表和原始LICENSE |
| 开发者疲劳 | 长期没有可玩构建 | 每周构建，按里程碑删功能 |

## 7. Demo发布标准

只有满足以下条件才公开：

- 10至15分钟完整循环
- 2个角色有明显不同体验
- 单人和双人均可完整游玩
- 4人模式即使内容较少也不崩溃
- 至少一个技能展示完整视觉进化
- 一个Boss拥有完整三阶段
- 低配画质档可用
- 许可证清单完整
