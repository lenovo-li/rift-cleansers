# 《裂界清扫者》玩法扩展设计方案

> 版本：v1.0  
> 日期：2026-10-02  
> 目标：提升爽快度、重玩性与构筑深度

---

## 执行摘要

基于当前已完成的核心系统，本文档提出一系列玩法扩展方案，核心目标：

1. **升级更频繁** - 从 10 分钟升到 20-30 级，改为 20 分钟升到 40-50 级
2. **技能池扩大** - 每个角色从 6 个技能扩展到 15-25 个可选技能
3. **技能栏限制** - 只能装备 6-7 个技能，构筑选择更有意义
4. **装备效果多样化** - 装备不只是数值，而是改变技能行为
5. **怪物密度提升** - 后期同屏怪物从 400 提升到 800-1200
6. **Boss 与精英变化** - 更多精英词缀组合，Boss 机制更复杂
7. **特效强化** - 后期越来越华丽，但保持可读性

---

## 当前系统分析

### 现有架构优势 ✅

从代码分析得出的现有优势：

1. **升级系统已成熟**
   - 三选一卡牌系统（`UpgradeSystem.roll_choices`）
   - 经验曲线可调（`GameSession.get_exp_required`）
   - 前 1 分钟 2 倍经验，1-3 分钟 1.5 倍经验

2. **技能系统高度模块化**
   - `AbilitySystem` 管理技能池（`skill_pool`）
   - 技能独立实现，四段进化已验证
   - 当前 24 个技能（4 角色 × 6 技能）

3. **装备系统灵活**
   - 32 件装备，通用 + 角色专属
   - 装备效果在 `CharacterStats` 和角色代码中实现
   - 每人最多 8 件装备

4. **敌人生成可扩展**
   - `SpawnDirector` 控制刷怪节奏
   - 存活上限曲线：0 秒 15 只 → 540 秒 400 只
   - 9 种精英词缀：传送、吸血、迅捷、装甲、爆裂、再生、冰霜、燃烧、巨型

5. **性能充足**
   - 500 敌人单机 396 FPS
   - MultiMesh 批量渲染，可扩展到 1000+
   - 空间网格优化碰撞查询

### 当前限制 ⚠️

1. **技能栏固定 6 个** - `MAX_SKILLS = 6`，所有技能都会装备
2. **游戏时长 10 分钟** - Boss 时间 `BOSS_TIME = 540s`（9 分钟）
3. **升级节奏** - 10 分钟约 25-30 级，后期升级慢
4. **技能池小** - 每个角色只有 6 个技能，没有选择空间
5. **装备效果单一** - 大部分是数值加成，缺少行为改变

### 2. 加快升级节奏 → 每 30-40 秒升一级

#### 当前升级节奏

```gdscript
# 当前经验公式：20 + 8L + 0.6L²
# Lv1→2: 28 经验
# Lv10→11: 148 经验
# Lv20→21: 428 经验
# Lv30→31: 788 经验
```

10 分钟约 25-30 级，后期升级间隔 1-2 分钟。

#### 改进方案

```gdscript
# core/systems/game_session.gd
func get_exp_required(level: int) -> float:
    # 新公式：15 + 5L + 0.3L²（降低基础需求和增长）
    return 15.0 + float(level) * 5.0 + 0.3 * float(level * level)

func get_exp_multiplier() -> float:
    # 延长 2 倍经验到 2 分钟，1.5 倍到 5 分钟
    if game_time < 120.0:
        return 2.0
    elif game_time < 300.0:
        return 1.5
    return 1.0
```

#### 预期升级节奏（20 分钟）

| 阶段 | 时间 | 等级范围 | 升级频率 |
|---|---:|---:|---|
| 起步 | 0-2 分钟 | 1→8 | 每 15-20 秒 |
| 成型 | 2-5 分钟 | 8→16 | 每 25-30 秒 |
| 压力 | 5-10 分钟 | 16→28 | 每 30-40 秒 |
| 爆发 | 10-18 分钟 | 28→45 | 每 40-50 秒 |
| Boss 战 | 18-20 分钟 | 45→50 | 每 60 秒 |

**目标：20 分钟达到 45-50 级，全程保持升级期待感。**

### 3. 扩展技能池 → 每角色 15-25 个技能

#### 当前技能池（每角色 6 个）

```gdscript

    "starting": ["shield_bash", "taunt"],
```

#### 扩展方案

每个角色从 6 个扩展到 **15-25 个技能**，分为：

**核心技能（6-8 个）** - 角色定位技能
- 铁卫：盾击、旋风斩、嘲讽、冲锋、震地、反射光环、**铁壁**、**怒吼**
- 元素术士：火球、冰枪、冰霜新星、闪电链、陨石、雷暴领域、**火焰风暴**、**冰墙**
- 影行者：影步、刀扇、死亡标记、刃舞、烟雾弹、处决、**暗影分身**、**致命打击**
- 牧师：圣光新星、惩击、圣域、神圣护盾、祝福、神圣干预、**净化**、**光明审判**

**通用技能（5-8 个）** - 所有角色可选
- 闪避强化、生命汲取、暴击打击、群体减速、护盾冲刺、光环类、召唤类

**进阶技能（4-6 个）** - 需要特定条件解锁
- 双元素组合技、终结技、变形技、召唤物强化

**实现方式**：

```gdscript
# content/characters/character_catalog.gd
"iron_guard": {

        # 核心技能（8 个）

        # 通用技能（6 个）

    "starting": ["shield_bash", "taunt"],  # 初始只有 2 个
}
```

**技能栏限制：最多装备 6-7 个技能**

```gdscript

# core/systems/spawn_director.gd
const ELITE_MOD_COMBOS: Dictionary = {
    "berserker": ["haste", "giant"],           # 狂暴巨人
    "ice_armor": ["frost", "armored"],         # 冰甲

# 后期（15 分钟后）精英有 30% 几率带 2 个词缀
func get_elite_mods(t: float, rng: RandomNumberGenerator) -> Array[String]:
    if t > 900.0 and rng.randf() < 0.3:
        var combo_key: String = ELITE_MOD_COMBOS.keys()[rng.randi() % ELITE_MOD_COMBOS.size()]
        return ELITE_MOD_COMBOS[combo_key]
    else:
        return [ELITE_MODS[rng.randi() % ELITE_MODS.size()]]
```

## 总结

本方案通过以下方式提升游戏爽快度：

✅ **升级更频繁** - 20 分钟 45-50 级，每 30-40 秒升一级  
✅ **技能选择更丰富** - 15-25 个可选技能，但只能装 6-7 个  
✅ **装备改变玩法** - 行为改变型装备，不只是数值  
✅ **怪物更密集** - 后期 800-1000 只同屏
