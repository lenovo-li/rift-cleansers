# 《裂界清扫者》工具、素材与许可证

## 1. 推荐工具

| 用途 | 工具 | 说明 |
|---|---|---|
| 游戏引擎 | Godot Engine | MIT，主工程、UI、渲染、粒子、音频和导出 |
| 代码 | VS Code或VSCodium | GDScript/C#编辑与Git集成 |
| 版本控制 | Git + Git LFS | 代码和大体积二进制资源 |
| 3D | Blender | 建模、骨骼、动画、简单贴图和glTF导出 |
| 2D | Krita | 位图裁切、图层、简单绘制 |
| 矢量 | Inkscape | SVG图标、UI和Logo |
| 音频 | Audacity | 裁剪、混音、响度和格式转换 |
| GPU调试 | RenderDoc | 帧捕获和GPU问题定位 |
| 项目管理 | GitHub Projects或Markdown | 任务、缺陷和里程碑 |

## 2. 推荐素材来源

### Kenney

适合：

- UI
- 图标
- 低模场景
- 角色
- 粒子图片
- 音效

大量资源采用CC0，但必须以具体资源包页面为准。[1]

### Godot Asset Library

适合：

- Shader
- 编辑器插件
- 示例工程
- 工具脚本

许可证并不统一。可以筛选CC0资源，但每个插件仍需单独检查。[2]

### OpenGameArt

适合：

- 2D图像
- 音效与音乐
- 模型
- 字体

平台包含CC0、CC-BY、CC-BY-SA等多种许可证。优先选择CC0；使用CC-BY时必须正确署名。[3]

### 其他候选

- KayKit
- Quaternius
- Poly Haven
- ambientCG
- Freesound

这些站点或作者常提供免费资产，但不能假设所有下载项均为同一许可证。必须逐项保存许可信息。

## 3. 许可证简化原则

### 优先使用

- CC0
- MIT
- BSD
- Apache-2.0
- 明确允许商业使用的CC-BY

### 谨慎使用

- CC-BY-SA：可能要求衍生内容采取相同许可证
- GPL插件：需要理解插件分发和组合方式
- 自定义免费许可：检查商用、修改和再分发限制

### 不使用

- 来源不明
- 仅限个人用途
- 禁止商业使用
- 无法找到原始作者或许可页面
- 从其他游戏中提取的素材

## 4. 资产登记模板

每个外部资产建立一条记录：

```yaml
asset_name: Fantasy Town Kit
author: Example Author
source_url: https://example.com/asset
license: CC0-1.0
download_date: 2026-09-27
modified: true
modifications: recolor, polygon reduction
credit_required: false
original_license_file: third_party_licenses/fantasy_town/LICENSE.txt
used_in: environment/city
```

## 5. 仓库结构

```text
third_party_licenses/
├─ godot/
│  └─ LICENSE.txt
├─ plugins/
│  └─ plugin_name/
│     ├─ LICENSE.txt
│     └─ SOURCE.txt
└─ assets/
   └─ asset_pack_name/
      ├─ LICENSE.txt
      ├─ SOURCE.txt
      └─ CHANGES.txt
```

## 6. 发布时的许可页面

游戏设置菜单中加入：

- 制作人员
- 开源许可证
- 第三方素材

同时在安装目录附带：

- `GODOT_LICENSE.txt`
- `THIRD_PARTY_NOTICES.txt`

Godot官方说明其引擎为MIT许可证，游戏本身可以采用其他许可证，但分发引擎二进制时要包含相应版权和许可声明。官方也提醒纹理、模型、声音、音乐和字体可能有各自的署名要求。[4][5]
